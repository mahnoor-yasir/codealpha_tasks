# CodeAlpha C++ Programming Internship Tasks

This repository contains the projects completed during my CodeAlpha C++ Programming Internship. These projects demonstrate core concepts of C++ Programming, Object-Oriented Programming (OOP), File Handling, Data Validation, and Problem Solving.

## Tasks Completed

### Task 1: CGPA Calculator

A C++ application that calculates GPA and CGPA based on course grades and credit hours.

#### Features
- Student information management
- Course-wise grade input
- Credit hour handling
- GPA and CGPA calculation
- Performance evaluation
- Report generation using file handling

#### Concepts Used
- Functions
- Arrays
- Conditional Statements
- File Handling
- Input Validation
